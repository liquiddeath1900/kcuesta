# Kcuesta

**¿A cómo está?** — Precios agrícolas de la República Dominicana, claros y al día.

Turns the Ministerio de Agricultura price data into something anyone can read in 5 seconds, plus WhatsApp alerts and price forecasts.

See [BUILD-PLAN.md](BUILD-PLAN.md) for the roadmap.

- Domain: kcuesta.com
- Data: Ministerio de Agricultura (ODbL, official)
- Stack: GitHub Pages + Neon + Python (GitHub Actions cron)
